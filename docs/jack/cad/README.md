# ملفات CAD — PT-JACK-250

## ⚠️ أول حاجة: ليه مفيش ملفات `.sldprt`؟

SolidWorks بيحفظ بصيغة **binary مقفولة ومملوكة لـ Dassault Systèmes**. مفيش أي طريقة تولّد `.sldprt` أو `.sldasm` صحيحة من غير ما SolidWorks نفسه يكون شغال ويحفظها. فأنا **مقدرش** أديك الملفات دي مباشرة.

اللي في الفولدر ده بيوصّلك لنفس النتيجة بأربع طرق، كلها مفتوحة وقابلة للتعديل:

| الفولدر | إيه هو | بيفتح في SolidWorks إزاي | قابل للتعديل؟ |
|---|---|---|---|
| `step/` | **مجسمات 3D حقيقية** بهندسة مضبوطة | `File > Open > *.step` | ✅ الجسم كامل. استخدم **FeatureWorks** (Insert > FeatureWorks > Recognize Features) عشان يحوّله لشجرة features قابلة للتعديل |
| `dxf/` | **مقاطع ثنائية الأبعاد** لكل قطعة | `File > Open > *.dxf` → Import to a new part sketch | ✅✅ بارامتري ١٠٠٪ — تعمل Extrude (شد) / Revolve (لفّ) بنفسك فتطلع شجرة نضيفة |
| `macros/` | **ماكروهات VBA** تبني القطعة جوه SolidWorks | VBA editor → `File > Import File` → Run | ✅✅ بتطلع شجرة features كاملة |
| `equations/` | **المتغيرات العامة** (global variables) | `Tools > Equations > Import` | ✅✅ تغيّر رقم واحد فيتحدّث الموديل كله |
| `python/` | **المصدر البارامتري الأصلي** | — | ✅✅✅ غيّر رقم وشغّل السكربت فتتولّد كل الملفات من أول وجديد |

**الطريقة اللي أنصح بيها:** افتح `step/PT-JACK-250-assembly.step` عشان تشوف الجاك كامل مركّب، وبعدين ابني القطع اللي هتعدّل فيها من `dxf/` أو `macros/` عشان تبقى بارامترية.

الكتل دي **محسوبة من الموديل مباشرة** (`python/mass_report.json`)، مش تقديرية.

### `dxf/` — مقاطع ثنائية الأبعاد

- `P1-nose-yoke-profile.dxf` و `P2-crossbeam-profile.dxf` — واجهة أمامية: الكونتور + الخروم + التفريغات. **Extrude** (شد) بالعمق المكتوب على الرسم.
- `P7-bearing-pad.dxf` — واجهة الوسادة (النعل)، Extrude 12.
- `*-revolve.dxf` — نصف مقطع طولي لكل قطعة مخروطة على المخرطة. فيه **خط محور على طبقة AXIS**؛ حوّله لـ centerline بعد الاستيراد و**Revolve 360°** (لفّ دورة كاملة).

الطبقات: `OUTLINE` (الكونتور) · `HOLES` (الثقوب) · `POCKETS` (التجاويف) · `AXIS` (المحور) · `NOTE` (ملاحظات).

### `macros/` — ماكروهات VBA

| الملف | يبني |
|---|---|
| `P3/P4/P5/P6/P8/P10-*.bas` | القطع المخروطة — اسكتش واحد + Revolve. **أقل مخاطرة** |
| `P1-nose-yoke.bas` | الحدوة — Extrude + قصّات (cuts) |
| `P2-crossbeam.bas` | الكمرة — Extrude + قصّات (cuts) |
| `PT-JACK-250-assembly.bas` | إدراج القطع في مجموعة جديدة + جدول المحطات |

**طريقة التشغيل:**
1. SolidWorks → `Tools > Macro > New...` → احفظ باسم القطعة (`.swp`)
2. في محرر VBA: `File > Import File...` واختار ملف `.bas`
3. شغّل `Sub main`

**ملاحظات تقنية:**
- الماكروهات بتستخدم **late binding** فمش محتاجة أي type library reference.
- بتختار المستويات **بالترتيب** مش بالاسم، فبتشتغل على أي نسخة لغة من SolidWorks.
- كل الوحدات في API الـ SolidWorks بالمتر — الماكروهات بتحوّل تلقائيًا.

> **⚠️ الماكروهات دي مكتوبة ومراجعة يدويًا لكن مش متجرّبة على SolidWorks حقيقي** — مفيش نسخة SolidWorks في البيئة اللي اشتغلت فيها. لو أي استدعاء فشل عندك (غالبًا `FeatureCut4` أو `FeatureExtrusion2` لو نسختك قديمة أو أحدث من المتوقع)، سجّل نفس العملية بـ Macro Recorder عندك وبدّل السطر. القطع المخروطة أبسط وأكبر احتمال تشتغل من أول مرة. **STEP و DXF مضمونين ١٠٠٪** ومش معتمدين على أي API.

### `equations/PT-JACK-250-globals.txt`

كل بارامترات التصميم كـ global variables. استوردها من `Tools > Equations > Import`، وبعدين اربط أبعاد الاسكتشات بيها (اكتب `=` في خانة البُعد واختار المتغير). بعد كده تغيير `"BORE"` من 50 لـ 45 بيعيد بناء القطعة كلها.

### `python/pt_jack_250.py` — المصدر البارامتري

ده **الماستر الحقيقي**. فيه `dict` اسمه `P` في أول الملف فيه كل بارامتر. غيّر أي قيمة وشغّل:

```bash
pip install cadquery
cd docs/jack/cad/python
python pt_jack_250.py     # يولّد كل ملفات STEP + تقرير الكتل
python gen_sw.py          # يولّد DXF + الماكروهات + ملف المعادلات
```

فتتولّد كل الملفات من أول وجديد ومتسقة مع بعضها. ده أسرع وأأمن من إنك تعدّل ملف ملف باليد.

```
X   محور الجاك — الصفر عند الوجه الأمامي لحدوة المقدمة، الموجب للخلف
Y   رأسي — الشق الجانبي بيفتح ناحية −Y
```

## حدود الموديل — اقرأها قبل ما تصنّع منه

الموديل ده **هندسة تصميمية**، مش موديل إنتاج نهائي. الحاجات دي **مش موجودة فيه** ولازم تضيفها:

1. **القلاووظات مرسومة بقطرها الداخلي (minor diameter) بس** — مفيش أسنان حقيقية. ضيف Cosmetic Thread أو Hole Wizard بالمقاسات: `M70×2` (طرفي الماسورة، غطاء الجلبة، تجويفين الكمرة) · `M24×1.5` (أنف العمود، البستم) · `M60×1.5` (القامطة) · `M52×1.5` (غطاء القامطة) · `M8` (مسامير الوسادات).
2. **مفيش كسر حرف (chamfer) ولا تدوير أركان (fillet)** غير على أركان التفريغات. متطلب الكلل في §5.6 من المستند الرئيسي بيقول **كل ركن داخلي R ≥ 8 mm** — ضيفها.
3. **مجاري الجوانات أبعادها اسمية** — راجعها على كتالوج المورد الفعلي قبل التشغيل (جدول §7.2).
4. **تيبر القامطة 7°** مرسوم على القيمة القياسية. **لازم تقيس التيبر الفعلي لطقم الودجات اللي اشتريته وتعدّل الموديل عليه** قبل ما تشغّل الماسورة.
5. **مفيش سماحات (tolerances) ولا GD&T** في المجسم. خُدها من جدول §8 في المستند الرئيسي.
6. **الخروم الهيدروليكية منمذجة Ø6 من غير سدادات** — ضيف تجاويف مسامير السد M8×1.
7. **المقبض والحواجز والخراطيم مش منمذجة.**

## قبل أي تصنيع

لو أي مصطلح هنا مش واضح، في **[قاموس مصطلحات الورشة](../README.md#قاموس-مصطلحات-الورشة)** في المستند الرئيسي بيربط كل كلمة باسمها الإنجليزي على الرسومات وفي كتالوجات الموردين.

الموديل ده يمشي مع **[المستند الرئيسي](../README.md)** — الحسابات وعوامل الأمان والخامات والمعالجات الحرارية وخطة الاختبار والمعايرة كلها هناك. مفيش قطعة تتصنّع من الـ CAD لوحده.

ولسه سارية كل التحذيرات: **مراجعة مهندس ميكانيكا مرخّص، اختبار ضغط واختبار حمل، معايرة، وودجات معتمدة مشتراة** — قبل أي استخدام على منشأ حقيقي.
