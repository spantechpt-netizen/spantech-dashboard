# جاك شد الكابلات (Mono-Strand Post-Tensioning Stressing Jack)
## تصميم تفصيلي — نسخة 250 kN (25 طن) بأسطوانتين

**رقم المشروع:** PT-JACK-250
**الإصدار:** A — 2026-09-15
**النوع:** Twin-cylinder, double-acting, mono-strand pull jack
**الشيش:** 7-wire strand Ø12.7 mm (0.5") و Ø15.24 mm (0.6") — إجهاد 1860 MPa

---

## ⚠️ تحذير هندسي لازم تقراه قبل أي حاجة

ده **تصميم جديد من الأول** مبني على نفس معمارية الجاك اللي في الصور — مش هندسة عكسية بمقاسات مقيسة من الجهاز الأصلي. الصور مفيش فيها قياسات، فأي حد يقول لك إنه قدر يطلع منها مقاسات دقيقة بيضحك عليك.

الجاك ده أداة **خطرة على الحياة**. لو الشيش قطع أو الإسفينة زقّت، الجاك بيطير في اتجاه محور الكابل بسرعة قاتلة. قبل ما تستخدم الجاك ده على أي منشأ حقيقي:

1. **لازم مهندس ميكانيكا مرخّص يراجع ويعتمد** الحسابات والرسومات دي.
2. **لازم اختبار ضغط (hydrostatic proof) واختبار حمل (load proof)** بالأرقام الموجودة في **§11** قبل أول استخدام.
3. **لازم معايرة (calibration)** للجاك مع المانومتر كوحدة واحدة مقابل load cell معتمدة.
4. **الإسفينات (wedges) اشتريها جاهزة معتمدة** من مورد أنظمة post-tension — متصنّعهاش محليًا في أول نسخة (§7.3).
5. **اتأكد إن الجاك مقبول من مورد نظام الـ PT** اللي شغال بيه في المشروع. كل نظام PT معتمد بـ jack محدد.

## 3. مبدأ العمل والمعمارية

الجاك ده **يشد بالدفع (push-to-pull)**:

```
   المرساة          حدوة              أسطوانتان              كمرة خلفية      قامطة
   (Anchor)        المقدمة          (تدفعان للأمام)          + مانيفولد     إسفينية
      |            [1]                 [2]                      [3]           [4]
  ====|=============================================================================  ← الشيش
      |             ↑                   →→→                      ←←←            ↑
      |        تستند على               العمودان                الجسم كله      تقبض
      |        وش المرساة              يخرجان                  يتحرك للخلف     على الشيش
```

1. **حدوة المقدمة (Nose Yoke)** — تستند بوجهها على كتلة المرساة. فيها شق جانبي عرض 22 mm عشان الجاك ينزل على الشيش من تحت من غير ما تفك أي حاجة.
2. **أسطوانتان هيدروليكيتان** بمحورين على بُعد ±80 mm من محور الشيش. عمودا البستم مربوطان بالقلاووظ في الحدوة.
3. **الكمرة الخلفية** = رأس خلفي للأسطوانتين + مانيفولد هيدروليكي + كمرة إنشائية، قطعة واحدة.
4. **القامطة الإسفينية** ملزوقة في وش الكمرة الخلفية، ماسكة الشيش.

لما تضخ: العمودان يطلعان → الحدوة ثابتة على المرساة → جسم الجاك كله (بالقامطة) يرجع للخلف → الشيش يتشد.

### 3.1 التزامن بين الأسطوانتين (أهم نقطة في التصميم ده)

ده السؤال اللي بيقع فيه كل حد بيعمل جاك بأسطوانتين. الإجابة: **متستخدمش flow divider أبدًا.**

التزامن هنا **كينماتيكي مش هيدروليكي**:
- الحدوة والكمرة **جسمان جاسئان** يربطان العمودين → الشوطان مجبران على التساوي هندسيًا.
- الأسطوانتان مغذّيتان من **نفس المانيفولد بقنوات متساوية الطول** → نفس الضغط.
- أي فرق احتكاك بين الأسطوانتين بيتحول لعزم على الإطار، والإطار متصمم يشيله.

**التحقق:** لو أسطوانة احتكاكها أعلى 10% → فرق قوة 13.7 kN → عزم إضافي = 13.7 × 80 = 1.10 × 10⁶ N·mm مقابل عزم التصميم 11.0 × 10⁶ N·mm = **10% زيادة فقط**، مستوعبة داخل عامل الأمان. ✔

كمان الشكل المتوازي (عمودان + كمرتان) بيمنع دوران الجسم حول محور الشيش تلقائيًا — مش محتاج anti-rotation key.

## 5. الحسابات الهندسية

كل الحسابات دي بالقيم القصوى (275 kN عند 700 bar) إلا لو مكتوب غير كده.

### 5.1 مقاس الأسطوانة

```
Force per cylinder   = 275 / 2 = 137.5 kN
Area req. @ 700 bar  = 137 500 N / 70 N/mm2 = 1786 mm2
Bore required        = sqrt(4 x 1786 / pi) = 47.7 mm   ->  select D50
```

| | القيمة |
|---|---|
| مساحة البستم A_p | π/4 × 50² = **1963.5 mm²** لكل أسطوانة |
| المساحة الكلية | 2 × 1963.5 = **3927 mm²** |
| مساحة الحلقة (جهة العمود) | π/4 (50² − 32²) = 1159 mm² × 2 = **2318 mm²** |
| ثابت القوة النظري | 3927 × 0.1 = **0.3927 kN/bar** |
| القوة عند 637 bar | 250.2 kN ← **نقطة التصميم** |
| القوة عند 700 bar | 274.9 kN ← السقف |

**جدول الضغط ↔ القوة** (ن = نظري، ف = فعلي بكفاءة η = 0.97، والفعلي بيتحدد بالمعايرة مش بالحساب):

| bar | 200 | 300 | 386 | 400 | 500 | 547 | 600 | 637 | 660 | 700 |
|---|---|---|---|---|---|---|---|---|---|---|
| kN (ن) | 78.5 | 117.8 | 151.6 | 157.1 | 196.4 | 214.8 | 235.6 | 250.2 | 259.2 | 274.9 |
| kN (ف) | 76.2 | 114.3 | 147.0 | 152.4 | 190.5 | 208.4 | 228.6 | 242.7 | 251.4 | 266.7 |

**ضغط الشد المستهدف عند 0.80 GUTS: شيش 0.5" ← 386 bar · شيش 0.6" ← 547 bar**

### 5.2 سمك جدار الأسطوانة — Ø50 داخلي / Ø70 خارجي (سُمك 10 mm)

نسبة الأقطار K = 70/50 = 1.40

**الخضوع (Lamé + von Mises عند سطح التجويف، طرف مقفول):**
```
sigma_vm = sqrt(3) * p * K^2/(K^2 - 1)
         = 1.732 * 70 * 1.96/0.96
         = 247.5 MPa
```
مع ماسورة مواصفة **Re ≥ 470 MPa** (اطلبها كده بالنص في أمر الشراء):
**SF = 470 / 247.5 = 1.90** ✔

عند ضغط الاختبار 955 bar: σ_vm = 337.7 MPa < 470 → لا يوجد انفعال دائم ✔
عند أقصى ضغط تشغيل حقيقي (547 bar لشيش 0.6"): σ_vm = 193 MPa → **SF = 2.43** ✔

**الانفجار (معادلة Faupel):**
```
p_burst = (2/sqrt(3)) * Re * ln(K) * (2 - Re/Rm)
        = 1.1547 * 470 * 0.33647 * (2 - 470/600)
        = 182.6 * 1.217 = 222 MPa = 2222 bar
SF      = 2222 / 700 = 3.17          [min. acceptable 2.5]
```

### 5.3 عمود البستم Ø32 — الحرج هو الانبعاج مش الإجهاد

العمود شغال **ضغط** (بيدفع على الحدوة)، فالانبعاج هو معيار التصميم.

**الإجهاد المباشر:**
```
A     = pi/4 * 32^2 = 804.2 mm2
sigma = 137 500 / 804.2 = 171 MPa
42CrMo4 QT at D32:  Rp0.2 >= 750 MPa   ->  SF = 4.39
```

**الانبعاج:**
```
Exposed length at full stroke = 200 + 20 = 220 mm
End-fixity: rod screwed into the yoke, guided by gland bush + piston
  (theoretically K = 0.5...0.65) -- assume K = 2.0 conservatively
L_e   = 2.0 * 220 = 440 mm

I     = pi * 32^4 / 64 = 51 472 mm4
i     = sqrt(I/A) = 8.0 mm          lambda = 440 / 8.0 = 55
l_lim = pi * sqrt(E / 0.8*Re) = pi * sqrt(210 000/600) = 58.8
lambda < l_lim  ->  inelastic range, use the Johnson parabola:

P_cr  = A * Re * [1 - Re * lambda^2 / (4 * pi^2 * E)]
      = 804.2 * 750 * [1 - 750 * 3025 / 8 290 464]
      = 804.2 * 750 * 0.7264 = 438 100 N = 438 kN

SF    = 438 / 137.5 = 3.19
```

> **ملاحظة تنفيذية:** لو زوّدت الشوط عن 200 mm من غير ما تكبّر العمود، عامل الأمان ده بينزل بمربع الطول. عند شوط 300 mm يبقى SF ≈ 2.1 — **مرفوض**. الشوط 200 mm قيد تصميمي مش اختيار عشوائي.

### 5.4 الكمرة الخلفية (7075-T651، 270 × 170 × 80)

```
Span L        = 160 mm            (cylinder centre distance)
Central load P = 275 kN           (from the gripper)
M = P*L/4      = 275 000 * 160 / 4 = 11.0e6 N.mm

Critical section (less gripper counterbore D66 x 25 and strand bore D22):
I     = 170 * 80^3/12 - 66 * (80^3 - 55^3)/12
      = 7.253e6 - 1.901e6 = 5.352e6 mm4
c     = 40 mm
sigma = 11.0e6 * 40 / 5.352e6 = 82.2 MPa
SF    = 470 / 82.2 = 5.7

Shear: tau_avg = 137 500 / 11 950 = 11.5 MPa
       tau_max = 1.5 * 11.5 = 17.3 MPa
```

### 5.5 حدوة المقدمة (7075-T651، 270 × 170 × 75)

الحمل بيرجع على المرساة من خلال **وسادتين مقسّيتين** على بُعد ±26 mm من المحور (جوه بصمة كتلة المرساة)، بينما العمودان على ±80 mm:

```
M at slot centreline = (P/2) * (80 - 26) = 137 500 * 54 = 7.425e6 N.mm

Critical section = the bridge above the slot only: 85 mm high x 75 mm deep
I     = 85 * 75^3/12 = 2.988e6 mm4 ;  c = 37.5 mm
sigma = 7.425e6 * 37.5 / 2.988e6 = 93.2 MPa
SF    = 470 / 93.2 = 5.0

Shear in the bridge: tau_max = 1.5 * 137 500 / 6375 = 32.4 MPa

Bearing on the anchorage casting:
Pad area  = 2 * 30 * 50 = 3000 mm2
sigma_brg = 275 000 / 3000 = 91.7 MPa
Ductile iron EN-GJS-500-7 (Rp0.2 = 320 MPa)  ->  SF = 3.5
```

### 5.6 الكلل (Fatigue) — النقطة اللي بتقتل جاكات الألومنيوم

سبيكة 7075-T651 **ملهاش حد كلل حقيقي** وحساسة جدًا للشروخ عند الأركان. الجاك ده ممكن يعمل 40 000 دورة في السنة، فالكلل هو **الحاكم الفعلي** مش الخضوع.

بحساب Goodman عند σ_max = القيمة القصوى المحسوبة، R ≈ 0 (نبضي)، σ_a = σ_m = σ_max/2،
σ_f (5×10⁸ دورة) = 160 MPa، Rm = 540 MPa، وعامل تركيز كلل **Kf = 1.8** لركن مشغّل بنصف قطر R8:

| القطعة | σ_max | σ_a = σ_m | Kf·σa/σf + σm/Rm | **SF** |
|---|---|---|---|---|
| الكمرة الخلفية | 82.2 | 41.1 | 0.462 + 0.076 = 0.538 | **1.86** ✔ |
| حدوة المقدمة | 93.2 | 46.6 | 0.524 + 0.086 = 0.610 | **1.64** ✔ |

**شروط إلزامية عشان الأرقام دي تفضل صح:**
1. كل الأركان الداخلية **نصف قطر ≥ 8 mm**. أي ركن حاد = الجاك يفشل بالكلل.
2. **Shot peening** (كرش بالكرات، Almen 0.20–0.30 A) لكل الأسطح المشغّلة في الحدوة والكمرة.
3. خشونة السطح **Ra ≤ 1.6 µm**، وفي مناطق الأركان Ra ≤ 0.8.
4. **فحص بالسائل النافذ (dye penetrant) كل 6 شهور** على الحدوة والكمرة — ومع أول شرخ، القطعة تُخردة ولا تُلحم أبدًا.
5. **عمر تصميمي 250 000 دورة**، وبعدها فحص كامل بالـ NDT أو استبدال.

> **بديل أقل خطرًا وأتقل:** لو مش هتلتزم ببرنامج الفحص ده، اعمل الحدوة والكمرة من صلب **42CrMo4 QT** بقطاعات أنحف (عمق 60 بدل 75/80). الوزن يزيد ≈ 6 kg ليصبح **≈ 38 kg**، لكن مسألة الكلل تختفي عمليًا. القرار ده قرار إداري مش هندسي: الألومنيوم يتطلب انضباط صيانة، الصلب يتطلب ظهر أقوى.

### 5.7 القامطة الإسفينية

```
Cone half-angle   alpha = 3.5 deg   (7 deg included = standard PT wedge taper)
Cone friction     mu1   = 0.10       (MoS2 greased)  ->  phi1 = 5.711 deg

Radial resultant on the strand:
R = F / tan(alpha + phi1)
  = 250 000 / tan(9.211) = 250 000 / 0.16218 = 1 541 kN

Required tooth-to-strand friction:
mu2 >= F/R = 0.162      -- serrated teeth give 0.30...0.50

Self-locking check:
mu1 = 0.10  >  tan(alpha) = 0.0612     (wedge cannot back out under load)

Equivalent internal pressure on the barrel:
mean cone dia = (25.0 + 33.6)/2 = 29.3 mm ;  effective length = 70 mm
p_eq = 1 541 500 / (pi * 29.3 * 70) = 239 MPa

Hoop stress at the bore, K = 65/29.3 = 2.218:
sigma_hoop = p * (K^2+1)/(K^2-1) = 239 * 5.92/3.92 = 361 MPa
42CrMo4 QT at D65:  Rp0.2 >= 850 MPa  ->  SF = 2.35
```

**قلاووظ الماسورة في الكمرة M60×1.5، تعشيق 35 mm:**
```
Shear area = pi * 60 * 35 * 0.5 = 3300 mm2
tau        = 250 000 / 3300 = 76 MPa
7075 shear yield = 0.577 * 470 = 271 MPa   ->  SF = 3.6
```

### 5.8 القلاووظات الأخرى

| الوصلة | المقاس | التعشيق | الحمل | τ | SF |
|---|---|---|---|---|---|
| غطاء الجلبة فوق الماسورة | M70×2 داخلي | 30 mm | 137.5 kN | 41.7 MPa | **6.5** |
| الماسورة في الكمرة | M70×2 خارجي | 30 mm | 137.5 kN | 41.7 MPa | **6.5** |

> **قاعدة حرجة:** **ممنوع منعًا باتًا** تقطع قلاووظ **داخل** تجويف الأسطوانة (Ø50). قلاووظ M64 جوه ماسورة Ø50/Ø70 بيرفّع الـ hoop stress لـ 759 MPa = **فشل مؤكد**. القلاووظ **دايمًا على القطر الخارجي** والغطاء يلبس من بره.

**كتف عمود البستم في الحدوة:** العمود له فلنشة Ø44 وتحتها **وردة مقسّاة Ø44/Ø24 × 5 (HRC 55)**:
```
sigma_brg on the aluminium = 137 500 / [pi/4 * (44^2 - 24^2)]
                           = 137 500 / 1068 = 129 MPa
7075 bearing strength ~ 1.5 * 470 = 705 MPa   ->  SF = 5.5
```
من غير الوردة والفلنشة (كتف Ø34) الضغط بيطلع 302 MPa والألومنيوم بينهرس تدريجيًا كل دورة.

### 5.9 نهاية غرفة الضغط في الكمرة

قرص دائري Ø50 مثبت الأطراف، سُمك 40 mm، ضغط 70 MPa:
```
sigma_max = 3*p*r^2/(4*t^2) = 3 * 70 * 625 / (4 * 1600) = 20.5 MPa  [negligible]
```

### 5.10 أحجام الزيت والطلمبة

```
Extend stroke  = 3927 * 200 = 785 400 mm3 = 785 cm3
Retract stroke = 2318 * 200 = 463 600 mm3 = 464 cm3
```
طلمبة يد عادية (≈ 2.9 cm³/ضغطة عند الضغط العالي) = **271 ضغطة للشوط الواحد**.
→ **استخدم طلمبة ذات سرعتين (two-speed) أو طلمبة كهربائية**. خزان ≥ 3 لتر.

### 5.11 الاستطالة (Elongation)

```
delta = F * L / (A * E)        E = 195 000 MPa (use the mill certificate value)
```

| الحالة | الطول | القوة | δ المحسوبة | عدد الأشواط (شوط 200) |
|---|---|---|---|---|
| 0.6"، كابل 30 م | 30 000 mm | 208.3 kN | **229 mm** | 2 |
| 0.6"، كابل 20 م | 20 000 mm | 208.3 kN | **153 mm** | 1 |
| 0.5"، كابل 25 م | 25 000 mm | 146.9 kN | **191 mm** | 1 |
| 0.5"، كابل 35 م | 35 000 mm | 146.9 kN | **267 mm** | 2 |

الاستطالة المقاسة لازم تكون في حدود **±5%** من المحسوبة (PTI / ACI 423). خارج الحدود دي: **قف وحقق** قبل ما تكمل — يا إما في احتكاك زايد في الغلاف، يا إما الشيش غلط، يا إما المانومتر محتاج معايرة.

> الاستطالة **وسيلة تحقق** مش هدف. الشد بيتوقف عند **الضغط المعاير** المستهدف، مش عند استطالة معينة.

### 7.3 الإسفينات — لماذا لا تصنّعها

الإسفينة قطعة بتحدد حياة الناس. عشان تشتغل صح لازم:
- هندسة سنون مضبوطة (خطوة 1.0 mm، عمق 0.3 mm، زاوية محددة) تعضّ الشيش **من غير ما تقطع** أسلاكه الخارجية
- كربنة 0.6–0.9 mm بصلادة HRC 60–62 على السطح مع قلب لدن HRC 30–35
- تطابق تيبر بين نصفي الإسفينة والماسورة في حدود دقائق قوسية
- اختبار static + dynamic معتمد على الشيش المستهدف

إسفينة مصنّعة غلط بتقطع الشيش عند 60% من حمله، أو بتزقّ فجأة والجاك يطير.

**اشترِ أطقم إسفينات معتمدة** من مورد نظام PT (طقم لـ 0.5" وطقم لـ 0.6")، و**اضبط تيبر ماسورة القامطة على التيبر الفعلي للإسفينة اللي اشتريتها** — متعملش العكس. قِس التيبر بمخروط قياس قبل تشغيل الماسورة النهائي.

### 9.2 تسلسل التشغيل — حدوة المقدمة (P1)

1. نشر اللوح 80 × 290 × 190 من 7075-T651
2. تسوية 6 أوجه إلى 75 × 270 × 170 (اترك 0.5 مم على الوجه الأمامي)
3. **تثبيت واحد:** تصفير على محور الشغلة → خرط/تفريز الشق 22 mm + نصف القطر R11 → ثقب وقلاووظ M24×1.5 للعمودين معًا **من غير فك** → تجويف مقعدي الوسادات
4. تفريز التجاويف المخففة والانسيابيات، **كل الأركان R8**
5. تشطيب الوجه الأمامي إلى الاستواء 0.05
6. إزالة حواف (كل الحواف R2) + تنظيف
7. **Shot peening** Almen 0.20–0.30 A
8. **أنودايز Type II 20 µm** (بعد كل التشغيل والقلاووظات)
9. فحص أبعادي + **فحص بالسائل النافذ** وتسجيل النتيجة كخط أساس

### 9.3 تسلسل التشغيل — الكمرة الخلفية (P2)

1. تسوية إلى 80 × 270 × 170
2. **تثبيت واحد:** خرط/تفريز تجويفي M70×2 على 160 C/C بعمق 30 + استمرار Ø50 H9 بعمق 10 → ثقب الشيش Ø22 → قلاووظ القامطة M60×1.5 بعمق 35 من الخلف → تجويف ماسورة الزقّ Ø26 H9 من الأمام
3. الثقب العميق Ø6 للقنوات: **قناتان متساويتا الطول تمامًا** من منفذ A إلى الغرفتين، وقناتان من منفذ B إلى المخرجين الجانبيين
4. قلاووظ المنافذ G1/4 على الوجه العلوي
5. **إزالة حواف كل تقاطعات الثقوب من الداخل** ثم سدّ نهايات الحفر بمسامير M8×1 + Loctite 2701
6. التجاويف المخففة، كل الأركان R8
7. Shot peening → أنودايز Type II
8. **اختبار ضغط للكمرة وحدها عند 955 bar قبل التجميع** — أرخص بكتير من اكتشاف تسريب بعد التجميع
9. فحص بالسائل النافذ + تسجيل

### 9.4 تسلسل التشغيل — عمود البستم (P4)

1. قطع Ø48 × 390 من 42CrMo4
2. خرط خشن مع ترك 2 mm

## 10. التجميع

### 10.1 الترتيب

1. نظّف كل القطع بالغسيل فوق الصوتي؛ لا تستخدم خِرَق تنسل

4. ركّب طقم جوانات الجلبة (S3–S6) في غطاء الجلبة بالترتيب من الداخل للخارج: صادّ → جوان عمود → حلقة توجيه → كاسحة

6. ركّب حلقة إيقاف الشوط (P10) في مقدمة التجويف
7. ركّب غطاء الجلبة على الماسورة مع S7: عزم **600 N·m** (مفتاح بنّص أو مفتاح شدّ) + Loctite 243 + مسمار تثبيت

9. اربط ماسورة القامطة في الكمرة: عزم **400 N·m**
10. اربط العمودين في الحدوة مع الوردتين المقسّاتين (P11): عزم **250 N·m** + مسمار تثبيت M8

| 10 | سائل نافذ على الحدوة والكمرة بعد اختبار الحمل | ASTM E165 | صفر مؤشرات |
| 11 | **المعايرة** | 10 نقاط من 10% إلى 100%، صعودًا وهبوطًا، مقابل load cell class 1 | شوف تحت |

### 11.1 معايير قبول المعايرة

| المعيار | الحد |
|---|---|
| الكفاءة η = (القوة المقاسة / 0.3927·p) | **≥ 0.95** |
| الخطية (linearity) | ≤ 1% من المدى الكامل |
| التخلفية (hysteresis) | ≤ 2% من المدى الكامل |
| التكرارية | ≤ 1% |

مخرج المعايرة معادلة: **F [kN] = a × p [bar] + b**، وتُطبع على لوحة ملصقة على الجاك ومطبوعة في شهادة المعايرة.

**الجاك والمانومتر يُعايران كوحدة واحدة ولا ينفصلان أبدًا.** اطبع نفس الرقم المسلسل على الاتنين. لو المانومتر اتكسر أو اتغيّر → **إعادة معايرة كاملة**.

**دورية إعادة المعايرة:** كل **6 شهور**، أو كل **100 ساعة تشغيل**، أو **بعد أي إصلاح**، أو بعد أي سقوط أو صدمة — أيهما أقرب (PTI M10.2).

## 12. التشغيل

شوف [DWG-07](drawings/DWG-07-operation.svg) للتسلسل المصوّر.

1. تحقق من سريان شهادة المعايرة ومن تطابق الرقم المسلسل مع المانومتر
2. ركّب إسفينات المرساة يدويًا ودقّها في مكانها
3. أنزل الجاك على الشيش من خلال الشق الجانبي؛ استند بالوسادتين مستويًا على كتلة المرساة
4. علّم الشيش عند الوجه الخلفي للجاك وسجّل القراءة المرجعية
5. اضخ ببطء. قف عند 20% من الهدف وراجع الاستقامة والاستناد
6. كمّل على مراحل (40 / 60 / 80 / 100%) وسجّل الضغط مقابل الاستطالة عند كل مرحلة
7. **قف عند الضغط المعاير المستهدف** — مش عند استطالة معينة
8. اثبت على الـ POCV بينما تتعشق إسفينات المرساة (احسب انسحاب المرساة ≈ 6 mm)
9. أنزل الضغط **ببطء** إلى الصفر ثم ارجع الأسطوانات
10. اضغط ذراع التحرير وارفع الجاك من الجنب
11. لو الاستطالة المطلوبة تحتاج شوطًا ثانيًا: أعد من الخطوة 3
12. قارن الاستطالة المقاسة بالمحسوبة؛ **خارج ±5% = قف وحقق**

### 12.1 سجل الشد (إلزامي لكل كابل)

كل صف لازم يحتوي: رقم الكابل · قطر الشيش · رقم المانومتر · رقم الجاك · تاريخ آخر معايرة · الضغط المستهدف · الضغط المحقق · الاستطالة المحسوبة · الاستطالة المقاسة · النسبة % · انسحاب المرساة · اسم وتوقيع الفني.

## 13. الصيانة

| الدورية | الإجراء |
|---|---|
| **كل يوم** | فحص بصري للخراطيم والوصلات؛ تنظيف العمودين؛ فحص سنون الإسفينة؛ التأكد من عدم وجود تسريب |
| **كل أسبوع** | شحم مخروط الإسفينة بـ MoS₂؛ فحص عزم مسامير الوسادات؛ تصريف الماء من خزان الطلمبة |
| **كل شهر** | فحص تآكل الوسادات (استبدل عند عمق حفر > 0.5 mm)؛ فحص سلامة الكروم على العمودين |
| **كل 3 شهور** | تغيير زيت الطلمبة أو فحص نظافته؛ فحص ضبط صمام الأمان |
| **كل 6 شهور** | **إعادة معايرة** · **سائل نافذ على الحدوة والكمرة** · فحص طقم الجوانات |
| **كل 500 دورة شد** | استبدال طقم الإسفينات (أو أبكر لو تآكل السن > 0.1 mm) |
| **كل سنة** | فك كامل، استبدال كل الجوانات، MPI على العمودين، قياس التجويف |
| **كل 250 000 دورة** | **فحص NDT كامل أو تخريد الحدوة والكمرة** (حد عمر الكلل) |

**قواعد غير قابلة للتفاوض:**
- ❌ لا تلحم أي قطعة من الألومنيوم أو تصلحها — الشرخ = تخريد
- ❌ لا تخلط نصفي إسفينة من طقمين مختلفين
- ❌ لا تستخدم طقم إسفينات 0.5" على شيش 0.6" أو العكس
- ❌ لا تتجاوز 700 bar تحت أي ظرف
- ❌ لا تفك أي وصلة والضغط قائم

## 14. السلامة

> **إذا فشل الشيش أو زقّت الإسفينات، الجاك وذيل الشيش ينطلقان في اتجاه محور الكابل بسرعة قاتلة.**

| # | الإجراء |
|---|---|
| 1 | **منطقة حظر 10 متر خلف الجاك** وفي خط محور الكابل. لا يمر أحد أثناء وجود ضغط |
| 2 | المشغّل يقف **على الجنب** دائمًا — أبدًا خلف الجاك |
| 3 | **حاجز/درع فولاذي** خلف الجاك عند الطرف الحي |
| 4 | **قيود اهتزاز (whip restraints)** على كل الخراطيم |
| 5 | **صمام أمان انفجار الخرطوم** على خط الفتح |
| 6 | نظارة أمان + خوذة + حذاء أمان لكل من في المنطقة |
| 7 | صمام الأمان **مضبوط ومختوم بالرصاص**؛ كسر الختم = إيقاف الجاك حتى إعادة المعايرة |
| 8 | الجاك 33 كجم — **يُرفع باتنين أو بحامل**. إصابات الظهر هي الإصابة الأشيع في الشد |
| 9 | ممنوع الشد في الأمطار أو الرياح الشديدة أو الإضاءة الضعيفة |
| 10 | كل مشغّل لازم يكون مدرّبًا وموثّقًا على النظام ده تحديدًا |

## 15. نسخة 20 طن لشيش 0.5" فقط

لو شغلك كله بلاطات بشيش 0.5"، النسخة دي أخف وأرخص:

| البند | 25 طن (الأساسية) | **20 طن (0.5" فقط)** |
|---|---|---|
| التجويف / العمود | Ø50 / Ø32 | **Ø45 / Ø28** |
| المساحة الكلية | 3927 mm² | **3181 mm²** |
| ثابت القوة | 0.3927 kN/bar | **0.3181 kN/bar** |
| القوة الاسمية | 250 kN @ 637 bar | **196 kN @ 616 bar** |
| القوة القصوى @ 700 bar | 275 kN | 223 kN |
| ضغط 0.80 GUTS لـ 0.5" | 386 bar | **476 bar** |
| المسافة بين المحورين | 160 mm | 150 mm |
| الأبعاد | 270 × 170 × 535 | **250 × 160 × 520** |
| الوزن | 33 kg | **≈ 26 kg** |
| زيت لكل شوط | 785 cm³ | 636 cm³ |

⚠️ لو عملت النسخة دي، **اكتب على الجاك بحروف بارزة: "0.5-inch strand ONLY — MAX 476 bar"**. استخدامها على 0.6" = تحميل زائد وكارثة.

## 17. الخطوات التالية المقترحة

1. **قرار الخامة:** ألومنيوم 7075 (33 كجم + برنامج فحص) أم صلب (38 كجم بلا قلق كلل) — §5.6
2. **تأكيد مقاس الشيش** الغالب في شغلك (0.5" أم 0.6") — يحدد النسخة الأساسية أم نسخة 20 طن
3. **اشترِ طقم الإسفينات أولًا** وقِس تيبرها الفعلي قبل تشغيل ماسورة القامطة
4. **تحويل الرسومات إلى CAD ثلاثي الأبعاد** واستخراج رسومات ورشة مقاسة لكل قطعة
5. **تحليل FEA** للحدوة والكمرة للتأكد من مواضع تركيز الإجهاد الفعلية (الحساب اليدوي هنا تحفظي لكنه لا يحدد بدقة أين سيبدأ الشرخ)
6. **مراجعة واعتماد** من مهندس ميكانيكا مرخّص
7. **بناء نموذج أولي واحد** واختباره بالكامل حسب §11 قبل أي إنتاج
