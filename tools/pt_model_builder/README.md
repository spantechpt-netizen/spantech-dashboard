# PT Model Builder: من المخطط لموديل RAM Concept (برنامج مستقل)

برنامج لوحده، منفصل عن Auto PT Suite ومش بيعدّل فيه. بياخد مخطط المكتب (DWG أو DXF، معماري أو إنشائي)، وفيه مرحلتين:

1. **مرحلة 1: DXF لكل زون.**
   - تحويل، تقسيم شيتات وزونات عند فواصل التمدد، والحد والفتحات والأعمدة والحوائط والكمرات.
   - السُمك والمناسيب والدروبات.
   - الطريقة كلها في [`../layerless_reader/pt_pipeline/FLOW.md`](../layerless_reader/pt_pipeline/FLOW.md)، والقواعد في `RULES.md`.
2. **مرحلة 2: موديل RAM Concept لكل زون.** بنفس كود Auto PT Suite، من غير كابلات:
   - المنشأ؛
   - دكتور الشبكة (قبل البناء، وبعد ما RAM يرفض الشبكة)؛
   - الأحمال: SDL، الحمل الحي، الحوائط المعمارية، حمل الحرف؛
   - خطوط الركايز وشرايح التصميم.

ممكن تشغّل مرحلة 1 بس، أو المرحلتين ورا بعض أوتوماتيك، أو مرحلة 2 بس على ملفات DXF جاهزة.

## التشغيل

دبل كليك على `PT Model Builder.bat`، أو:

```bash
python -m ptmb --gui
python -m ptmb plan.dwg -o out --stage dxf                          # مرحلة 1 بس
python -m ptmb plan.dwg -o out --stage both --cpt template.cpt      # المرحلتين
python -m ptmb out/ --stage ram --cpt template.cpt                  # DXFs جاهزة -> RAM
```

محتاج:
- بايثون عليه `ezdxf` و`shapely` و`matplotlib` (`pip install -r requirements.txt`).
- لمرحلة 2: RAM Concept متسطّب، وموديل template (`.cpt`). كل زون بتتبني في نسخة من الـ template، والـ template نفسه مابيتلمسش.

## الشاشة

| الجزء | فيه |
|---|---|
| Files | المخطط (أو ملفات الزونات في وضع 3)، فولدر الناتج، والوضع: 1 / 2 / 3 |
| RAM Concept | الـ template، فولدر RAM Concept Python API، وتحليل بعد البناء (اختياري) |
| Defaults | سُمك البلاطة، سُمك الدروب، عمق الكمرة. **بيتاخدوا بس لما الرسمة مافيهاش القيمة** |
| Loads | SDL والحمل الحي، الحوائط المعمارية (كثافة × ارتفاع × معامل الفتحات)، حمل الحرف |
| Support lines / design strips | رسم خطوط الركايز وشرايح التصميم في الموديل |
| Drawing reader | فولدر `pt_pipeline` و`dwgread` (جايين جوه الـ zip، والبرنامج بيلاقيهم لوحده) |

## القيم الناقصة من الرسمة: البرنامج مابيطلعش أخطاء، بيكمّل بالافتراضي وبيقول

| الناقص | اللي بيحصل |
|---|---|
| سُمك البلاطة | سُمك البلاطة الافتراضي |
| سُمك الدروب | سُمك الدروب الافتراضي |
| عمق الكمرة | العرض من المخطط، والعمق = عمق الكمرة الافتراضي (`B4(300X?)`) |
| المناسيب | السقف كله منسوب واحد (صفر). لو فيه مناسيب: السقف الكبير = صفر، والباقي بفرقه بالمم (`toc` في RAM) |

**قبل البناء في RAM بتطلع رسالة تأكيد** زي رسالة Auto PT Suite. بتقول:
- السُمك اللي اتقرا من الرسمة، والزونات اللي مالهاش سُمك والافتراضي اللي هياخده؛
- عدد الدروبات والكمرات اللي من غير سُمك أو عمق؛
- المناسيب لكل زون، أو "السقف كله منسوب واحد"؛
- الأحمال؛
- وهل شرايح التصميم هتترسم ولا لأ.

OK بيبني، وCancel بيرجّعك للإعدادات. في وضع 2 قبلها بتطلع شاشة تختار فيها الزونات اللي هتتبني.

## الكود

| الملف | الشغل |
|---|---|
| `ptmb/stage1.py` | بيشغّل `pt_pipeline` في process لوحده (Stop بيوقفه) |
| `ptmb/preflight.py` | بيقرا ملف كل زون: إيه المكتوب وإيه الناقص، ونص رسالة التأكيد |
| `ptmb/stage2.py` | زون ← موديل RAM: قراءة، تنضيف، بناء، أحمال، شرايح، حفظ، تحليل |
| `ptmb/app.py`، `ptmb/cli.py` | الشاشة وسطر الأوامر |
| `ptmb/settings.py` | الإعدادات في `~/.pt_model_builder.json` (أول مرة بتبدأ من إعدادات Auto PT Suite لو موجودة) |
| `build_core.py` | بيولّد `ptmb/ram_core.py` من ملف Auto PT Suite |

### `ram_core.py`

كود المرحلة 2 نفسه (قراءة الـ DXF، `RamSession`، `build_structure_in_ram`، دكتور الشبكة، الأحمال، الشرايح) جاي من Auto PT Suite:

```bash
python build_core.py Auto_PT_Suite_v397_CAD_Reader_AI_patched.py
```

- `build_core.py` بيمشي على شجرة الكود من الدوال المطلوبة، وبيطلّع كل اللي بتستخدمه بس: حوالي 255 تعريف و10,000 سطر، من غير واجهة ولا كابلات.
- لو البرنامج اتحدث، شغّل الأمر تاني.
- `ram_core.py` **مش في الريبو**، لأن الريبو عام والبرنامج مرخّص. بيتولد عندك، وجاي جاهز جوه الـ zip.

## الاختبارات

```bash
AUTOPT_SRC=Auto_PT_Suite.py python -m pytest tests -q
```

- مرحلة 1 ورسالة التأكيد على رسومات صناعية: دروب من غير سُمك، ومن غير مناسيب.
- مرحلة 2 على جلسة RAM وهمية: زون بمنطقة منسوب −100 ودروب من غير سُمك. المنسوب بيدخل `toc`، والدروب بياخد الافتراضي.
