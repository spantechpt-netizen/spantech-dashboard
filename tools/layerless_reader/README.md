# Layerless Reader

بيحوّل مخطط DXF (معماري أو إنشائي) لملف DXF نضيف يدخل على **Auto PT Suite**
مباشرةً، **من غير ما يعتمد على أسماء الليّرات**.

الناتج بنفس صيغة `_write_clean_dxf` في البرنامج (مليمتر، `$INSUNITS = 4`)،
وأسماء الطبقات دي بيعرفها `guess_role` بثقة 1.0، فشاشة الليّرات بتتملي لوحدها:

| الطبقة | الدور في البرنامج | المعنى |
|---|---|---|
| `PT-Clean-Columns` | column | أعمدة |
| `PT-Clean-Walls` | wall | حوائط خرسانية (ركائز) |
| `PT-Clean-Arch-Walls` | arch_wall | حوائط مباني (أحمال خطية) |
| `PT-Clean-Openings` | opening | فتحات (أسانسير، شفت، بير سلم) |
| `PT-Clean-Boundary` | slab | حد البلاطة |
| `PT-Clean-Beams` | beam | كمرات (من ملف إنشائي بس) |

## التشغيل

```bash
pip install -r requirements.txt

python layerless_reader.py plan.dxf                  # -> plan_clean.dxf + review + report
python layerless_reader.py plan.dxf --kind struct    # ملف إنشائي
python layerless_reader.py plan.dxf --units cm       # لو الوحدة مش مظبوطة في الملف
python layerless_reader.py sheet.dxf --window 0,0,60000,40000   # مسقط واحد من شيت فيه كذا مسقط
python layerless_reader.py plan.dxf --ai --crops crops/          # Claude يراجع العناصر المتوسطة
```

الملفات اللي بتطلع:

- `plan_clean.dxf`: يدخل على Auto PT Suite.
- `plan_clean_review.dxf`: بنفس وحدة الرسمة الأصلية، يتركّب عليها كـ XREF.
  الأخضر مؤكد، والأصفر محتاج مراجعة، والأحمر مرفوض، وجنب كل عنصر سبب القرار ودرجة الثقة.
- `plan_clean_report.json`: الأعداد، والفحوص، وقايمة العناصر اللي محتاجة مراجعة.

## بيتعرف على العناصر إزاي (من غير أسماء)

1. **الوحدة**: من `$INSUNITS` بعد فحص معقولية مقاس المبنى ونصف قطر الأبواب.
   لو الـ header غلط أو فاضي، بيستنتجها من نفس الحاجتين دول.
2. **المحاور**: خط طويل في آخره دايرة جواها حرف أو رقم، أو خط نوعه CENTER/DASHDOT.
3. **الحاجات اللي بتتشال**:
   - الأبواب: قوس 60–100° مع الضلفة.
   - السلالم: 5 خطوط متوازية أو أكتر بنفس الطول، والمسافة بينها 0.22–0.40 م.
   - البلوكات الصغيرة (عفش وصحي).
   - الأبعاد والنصوص.
   - الخطوط المخفية: غالبًا حاجة فوق الدور، فمش بتتحسب حوائط.
4. **الأعمدة**: أي شكل مقفول بمقاس عمود (بولي لاين، أو دايرة، أو hatch، أو 4 خطوط بتقفل مستطيل) بياخد درجة ثقة:
   - معبّى: +0.35
   - على تقاطع محاور: +0.25
   - مقاس متكرر: +0.15
   - على صف أعمدة: +0.10
   - فيه عناصر جواه، زي ترابيزة أو سرير: −0.35
5. **الحوائط**: بيزاوج الوشوش المتوازية اللي بينها 7–45 سم. بعدها بيفرق بين الخرساني والمباني:
   - تعبئته نفس تعبئة الأعمدة: +0.4
   - pattern خرسانة: +0.3
   - pattern طوب: −0.3
   - حوالين سلم أو أسانسير: +0.2
   - سمكه ≤ 15 سم: −0.3
6. **الفتحات**: خطين قطريين بيتقاطعوا في منتصفهم (علامة X)، وبير السلم.
7. **حد البلاطة**: الغلاف الخارجي للحوائط والأعمدة (closing).
8. **Claude** (`--ai`، اختياري): بيشوف بس العناصر اللي ثقتها متوسطة، كصورة crop.
   بيرجّع دور من قايمة ثابتة بـ JSON schema، ومايرجّعش أي إحداثيات.
   ولو ثقته أقل من 0.7 القرار مابيتغيّرش.

## الاختبارات

```bash
python -m pytest test_layerless_reader.py -q
```

`make_sample.py` بيعمل رسمة معمارية أسماء ليّراتها مضلِّلة عن قصد
(الأعمدة على `A-FURN` والمحاور على `WALLS`...). الاختبارات بتتأكد إن النتيجة واحدة
لما كل حاجة تبقى على ليّر 0، أو الأسماء تتقلب، أو الوحدة تبقى mm/cm/m من غير `$INSUNITS`،
أو الرسمة تتلف 27°، أو الخطة كلها تبقى جوه بلوك.
وفيه كمان اختبار لمسار الـ AI بـ client وهمي.

## حدود معروفة (النسخة 0.1)

- البلكونات والكابولي اللي مرسومة بخط واحد مش جوه الغلاف. راجع حد البلاطة.
- بير السلم بيطلع فتحة "للمراجعة" على شكل مستطيل حوالين القلبات.
- الحوائط المنحنية بتتقرا لو نصف قطرها أكبر من 1.8 م.
- الشيت اللي فيه كذا مسقط محتاج `--window` لكل مسقط.
- DWG: حوّله DXF الأول (ODA File Converter أو من AutoCAD).

التحقق الهندسي مسؤولية المهندس المصمم. راجع ملف المراجعة قبل RAM Concept.
