# تعديلات Auto PT Suite

`auto_pt_suite_patch.diff` بيتطبّق على `Auto_PT_Suite_v397_CAD_Reader_AI.py`:

```bash
patch Auto_PT_Suite_v397_CAD_Reader_AI.py < auto_pt_suite_patch.diff
```

فيه 3 تعديلات:

1. **قراءة المقاسات المكتوبة** على العناصر وإدخالها لـ RAM بيها:
   - `t=`
   - `SE=`
   - `P=`
   - `LEVEL` / `ZONE` / `DROP`
   - `POUR STRIP ... RELEASE FX FY`
   - `MARK(WxD)` للكمرات
2. **دكتور الشبكة قبل البناء** (`mesh_doctor`):
   - دمج الرؤوس القريبة؛
   - شيل الأضلاع الصغيرة؛
   - لزق حد البلاطة على الوش الخارجي للكمرة؛
   - قص الكمرات اللي برّه البلاطة؛
   - تحويل الفتحة اللامسة للحد لتجويف؛
   - دمج الفتحات المتداخلة؛
   - شيل الشرايح الرفيعة؛
   - غلق الفجوات الصغيرة عند أطراف الكمرات؛
   - حل تداخل المناطق اللي ليها نفس الأولوية.
3. **إصلاح أخطاء RAM بعد الـ meshing** (`mesh_doctor_retry`):
   - تصنيف رسالة RAM؛
   - مسح العناصر اللي البرنامج رسمها بس، وإعادة بنائها بتسامح أعلى (مستويين)؛
   - تجربة مقاسات عناصر شبكة تانية؛
   - لو كل ده فشل، طباعة الأماكن المشكوك فيها بالإحداثيات.

الاختبارات: `../tests/test_mesh_doctor.py`، ومحتاجة `AUTOPT_SRC`.
